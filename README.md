## تغییرات V5.0.1 (اصلاح مشکل بازیابی داده)

### 🔴 مشکل ریشه‌ای حل‌شده:
- **مسئله**: داده‌ها وقتی مرورگر بند شود یا cache پاک شود از بین می‌رفتند
- **دلیل**: وابستگی تنها به localStorage (قابل حذف توسط کاربر/مرورگر)
- **راه‌حل**: سیستم backup چند‌لایه اضافه شد

### ✅ ویژگی‌های جدید:

#### 1️⃣ **Backup خودکار فوری (Immediate)**
- هر تغییری (تراکنش، دارایی، یادداشت) فوری backup می‌شود
- نه منتظر معیار زمانی

#### 2️⃣ **سه‌لایه‌ی ذخیره‌سازی (Redundancy)**
- **لایه اول**: `localStorage` (سریع، اما قابل حذف)
- **لایه دوم**: `IndexedDB` (پایدار‌تر، جداگانه)
- **لایه سوم**: `PERSISTENT_BACKUP_KEY` (فاقد‌المثال، بدون رمزنگاری)

#### 3️⃣ **بازیابی خودکار (Silent Auto-Restore)**
- در صفحه‌بارگذاری، اگر `localStorage` خالی باشد:
  1. ابتدا IndexedDB را بررسی می‌کند
  2. سپس emergency backup را بررسی می‌کند
  3. خودکار داده‌ها را بازیابی می‌کند (بدون درخواست کاربر)

#### 4️⃣ **Backup خودکار با بازه‌ای (Scheduled)**
- روزانه (Default) یا هفتگی
- تنظیمات پیش‌فرض: **فعال** + **روزانه**

#### 5️⃣ **بازیابی دستی (Manual Restore)**
- دکمه "بازگردانی" در تنظیمات
- تائید قبل از بازیابی

### 🛡️ حفاظت اضافی:

- اگر IndexedDB ناموفق باشد، خودکار emergency fallback استفاده می‌شود
- Config backup در IndexedDB ذخیره می‌شود (افزونه روی localStorage)
- Validation کامل برای داده‌های بازیابی‌شده

### 📊 وضعیت Backup:

تنظیمات → بخش "پشتیبان‌گیری خودکار" شامل:
- ✓ وضعیت (فعال/غیرفعال)
- ✓ بازه‌ی Backup (روزانه/هفتگی)
- ✓ آخرین اجرا (تاریخ/ساعت)
- ✓ تعداد نسخ‌های ذخیره‌شده (حداکثر 5)
- ✓ دکمه "بازگردانی آخرین پشتیبان"
- ✓ هشدار فضای ذخیره‌سازی

## مثال استفاده

```
1. داده‌های خود را وارد کنید (تراکنش، دارایی، یادداشت)
2. خودکار هر 10 ثانیه یک backup ایجاد می‌شود
3. حتی اگر مرورگر بسته شود یا cache پاک شود:
   → صفحه‌ی بعدی خودکار داده‌ها را بازیابی می‌کند
4. در تنظیمات، می‌توانید وضعیت backup را مشاهده کنید
5. اگر نیاز باشد، می‌توانید دستی بازگردانی کنید
```
