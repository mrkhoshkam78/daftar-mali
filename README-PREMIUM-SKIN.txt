DAFTAR MALI — Bootstrap Premium Skin
=======================================

این بسته شامل پوسته جدید Bootstrap برای پروژه Daftar Mali است.

فایل‌ها:
- bootstrap-skin.css
- bootstrap-skin-install.txt

نحوه اتصال:
1) فایل bootstrap-skin.css را کنار index.html و styles.css قرار دهید.
2) در index.html، بعد از styles.css این خط را اضافه کنید:

<link rel="stylesheet" href="bootstrap-skin.css?v=1.0.0">

نکته:
منطق مالی، داده‌ها، LocalStorage، تراکنش‌ها و ماژول‌های JavaScript تغییر داده نشده‌اند.

این بسته «لایه پوسته» است و کل سورس repository را شامل نمی‌شود؛ به‌دلیل محدودیت دسترسی دانلود مستقیم آرشیو GitHub در این محیط، امکان بسته‌بندی خودکار کل repository همراه با فایل‌های باینری اصلی (logo.png / favicon.png / bg-immersive.jpg) فراهم نشد.
